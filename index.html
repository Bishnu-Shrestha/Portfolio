Simple To Do List App:


This is a React-based To-Do list application that I recently developed as my take on the classic task manager. The app allows users to add, edit, and delete tasks, as well as mark them as completed. To enhance the user experience, I implemented local storage support, ensuring that tasks persist even after refreshing the page. This project helped me strengthen my skills in React state management, event handling, and working with browser storage. Feel free to check it out! by clicking here .



One Piece anime site:


As a One Piece fan, I created this website during the early days of my high school journey to explore clean and informative web design. The first section covers the origin of the manga and anime series, while the second features interactive profile cards for each of the Straw Hat Pirates. Through this project, I learned about structuring content for readability, designing cards that display key information at a glance, and handling the DOM using JavaScript to dynamically generate cards. Additionally, I experimented with basic CSS animations, which helped me improve my styling skills. Feel free to check it out! by clicking here.


Simple Pizza ordering form:


This is a simple yet responsive form designed with proper validation using JavaScript. It ensures that users can only submit the form when all required input fields are correctly filled and a payment method is selected. Upon successful order placement, the form provides user feedback. Although this project is one of my earliest works—built in HTML, CSS and JS during the start of my high school journey—it does not include a database and hasn’t been hosted. Despite its simplicity, it helped me understand form validation, user input handling, and responsive design for both mobile and desktop devices.
